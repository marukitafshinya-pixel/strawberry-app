# いちご狩り 予約・会計アプリ　スタッフ向けの使い方

## はじめに

- スタッフ画面：`https://ichigo-test-d0fa2.web.app/staff/`（本番に切り替えたらアドレスが変わります）
- お客様の予約ページ：`https://ichigo-test-d0fa2.web.app/`
- ログインには、管理者から伝えられたメールアドレスとパスワードを使います。

### ホーム画面に追加する（iPad・iPhone）
1. Safariでスタッフ画面を開く
2. 下（iPadは上）の共有ボタン（□に↑）を押す
3. 「ホーム画面に追加」→「追加」
4. ホーム画面のいちごのアイコンから、アプリのように開けます

---

## ホーム（ログインして最初の画面）
- 今日の予約件数・人数、来店済の人数、今日の売上、承認待ちのリクエストが出ます。
- 数字を押すと、予約管理（今日）や日次締めが開きます。
- 下にメニューのボタンがあります。

---

## 1日の流れ

| いつ | すること | 使う画面 |
|---|---|---|
| 朝 | 今日の予約と、承認待ちのリクエストを確認 | ホーム・予約管理 |
| お客様が来たら | 予約の「来店」を押す | 予約管理 |
| お帰りのとき | 「会計」→ 現金か売掛で確定 → 必要ならレシート・領収書 | 会計 |
| 閉店後 | その日の売上・現金の合計を確認 | 日次締め |

---

## 予約管理

- **日付の切り替え**：「‹ 前日」「翌日 ›」、または日付欄で選ぶ
- 時間枠ごとに「予約人数／定員」と残り人数が出ます。赤い「定員超過」は、定員より多く入っている印です。
- **予約を追加**：「＋ 予約を追加」→ 日付・時間・プラン・人数（＋−）・お名前 →「保存する」
  - 電話・メール・メモは空欄でも大丈夫です。
  - 定員を超えるときは確認が出ます。「OK」で登録できます。
- **来店**：お客様が来たら「来店」を押す
- **変更・キャンセル**：「編集」→ 内容やステータスを変えて「保存する」
  - キャンセルした人数は、空き枠に戻ります。
  - 「削除」は、間違えて入れた予約を消すときだけ使います（会計済みの予約は消せません）。

### ステータスの意味
| ステータス | 意味 | 定員に数える？ |
|---|---|---|
| リクエスト | Webから、定員を超えて申し込まれたもの（お店の承認待ち） | 数えない |
| 予定 | 仮の予約 | 数える |
| 確定 | 予約が決まったもの（Web予約は定員以内なら自動で確定） | 数える |
| 来店済 | 来園済み | 数える |
| キャンセル | 取り消し | 数えない |

### リクエストへの対応
1. メニューや予約管理に「リクエスト ◯件」と出たら、お客様に電話かメールで連絡する
2. 受けられる →「承認」を押す（定員を超える場合は確認が出ます）
3. 受けられない →「編集」→ ステータスを「キャンセル」にして保存

---

## 会計

1. 予約管理で「来店」→「会計」を押す（人数×料金が自動で入ります）
   - 予約のないお客様：メニューの「会計」から
2. お土産・ドリンクなどのボタンを押して追加（同じ商品を押すと数量が増えます）
3. 数量は＋−、割引は明細ごとの「%引」か、下の「全部に◯%引きを かける」
4. 支払方法を選ぶ
   - **現金**：「お預かり」を入れると、おつりが出ます
   - **売掛**：お客様名（必須）と、分かれば回収予定日を入れます
5. 「◯◯で確定」を押す
6. 必要なら「レシート・領収書を出す」→「印刷する」

### レシート・領収書
- 「レシート」「領収書」を切り替えます。領収書は、宛名・但し書き・発行日を入れられます。
- 用紙は「レシート幅」か「A4」を選べます。印刷の画面でプリンター（AirPrint）を選びます。
- あとから出し直すときは、日次締めの会計履歴から開けます。

### 会計を間違えたとき
- 日次締め → 会計履歴の行を押す →「この会計を取り消す」
- 売掛の会計を取り消すと、売掛一覧からも消えます。予約は「会計前」に戻るので、会計し直せます。

---

## 売掛管理
- 売掛で会計すると、自動でここに入ります。
- お金を受け取ったら「回収済にする」
- 回収予定日を過ぎると、赤く表示されます。
- 会計を通さない売掛は「＋ 売掛を手入力」で追加できます。

## 日次締め
- 日ごとの売上合計・現金・売掛・会計件数と、分類ごとの売上
- その日に回収した売掛も表示されます（現金で受け取った場合、レジの現金はその分多くなります）

## ダッシュボード・集計
- **ダッシュボード**：今日の予約、今月の売上、未回収の売掛、グラフ
- **集計（期間指定）**：期間を決めて、予約と売上をまとめて確認。「CSVで書き出す」でExcelに持っていけます。

---

## 管理者だけができること
| 画面 | できること |
|---|---|
| 設定 | お店の情報・営業期間・臨時休業日・予約の受付期間・時間枠と定員・料金区分・プラン・商品 |
| 予約管理 | 「この日の定員を変える」「Web受付を止める」「まとめて受付停止・再開」 |
| スタッフ管理 | スタッフの追加、名前・権限・パスワードの変更、無効にする |
| 過去売上の取り込み | AirレジのCSVを取り込む |

## 困ったとき
| こんなとき | どうする |
|---|---|
| 画面が古いまま・ボタンが出ない | ページを再読み込みする（アプリを閉じて開き直す） |
| 「権限がありません」と出る | 管理者に、スタッフ登録されているか確認してもらう |
| 「このアカウントは無効になっています」 | 管理者に有効にしてもらう |
| パスワードを忘れた | 管理者にスタッフ管理で新しいパスワードを設定してもらう |
| 保存に時間がかかる | 最初の1回は10秒ほどかかることがあります。電波も確認してください |
